# Lilypad — APK

Casca Android offline para `projects/lilypad-brincadeira`.

O APK empacota a interface, os sprites e os quatro áudios; não depende de servidor local para abrir.

Para gerar novamente:

```sh
cd projects/lilypad-apk
sh build.sh
```

Os arquivos são copiados para `Documentos/Lilypad-Brincadeira.apk` e `Download/Lilypad-Brincadeira.apk`.
